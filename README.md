## 🛠️ Development & Build Setup

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn / pnpm

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
The optimized static build will be placed in the `dist/` directory.
